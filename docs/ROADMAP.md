# Roadmap

- Preserve and label the latest enclosed-flight logs, separating props-off and props-on records.
- Independently validate height and vertical-speed fields against reference measurements.
- Characterise communication loss in a controlled props-off setup, distinguishing missing outbound commands from Wi-Fi disconnection.
- Establish a physical emergency-recovery method independent of the command link.
- Map joystick axes and flight readiness/mode indicators through labelled observations.
- Consolidate duplicated transport code after preserving and regression-testing the current baseline.
- Integrate an explicitly labelled simulation/live touchscreen dashboard.
- Investigate video and supported battery/GPS telemetry without presenting guessed values as real measurements.

No roadmap item is claimed complete merely because a UI or timer exists.
